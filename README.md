# Share Sustenance: Bridging Food Surplus and Insecurity for a Sustainable Future

> **Authors:** Ragini Sharma, Sahil Marathe, Tejaswi More, Swaroop Patil, Prathamesh Pachupate

---

## 📌 Project Overview
"Share Sustenance" is an Android-based food sharing and tracking platform designed to connect individuals, local communities, and organizations to reduce food waste and combat food insecurity. 

### Key Features
* **Multi-Role Access:** Dedicated portals for Donors, Delivery Personnel, and NGOs.
* **Real-Time Food Tracking:** Interactive location map displaying active donation pins and status updates.
* **Reward System:** "Food Coins" incentive scheme allowing donors to redeem rewards for completed contributions.
* **Resource Sharing:** Supports donations for food, clothes, and books.

---

## 🛠️ Tech Stack
* **Language:** Java
* **Frontend:** XML
* **Backend & Auth:** Firebase Realtime Database & Authentication
* **Mapping:** Location/Maps API integration
